QuestForge

About

QuestForge is a Python-based text adventure engine where players explore different locations, move between rooms, and discover hidden places.

Current Features

Explore a village, forest, and cave.

Move between rooms using directional commands.

Use the look command to view the current room description again.

Discover a hidden cave and complete the adventure.

Receive messages when an invalid direction is entered.

How to Run

Make sure Python 3 is installed.

Run the game using:

python3 launch_console.py

Project Structure

launch_console.py — Main game engine.

tests/test_game.py — Automated tests for game functionality.

RELEASE_NOTES.md — Project release history.

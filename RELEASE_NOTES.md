QuestForge — Release Notes

Version 1.0 — Initial Development

Features

Created a basic text-adventure game.

Added village, forest, and cave locations.

Added directional movement between rooms.

Added a look command to display the current room description.

Added a message for invalid movement directions.

Testing

Added automated tests for room descriptions and player movement.

Future Improvements

Add inventory and collectible items.

Introduce more locations and challenges.

Expand the adventure storyline.
